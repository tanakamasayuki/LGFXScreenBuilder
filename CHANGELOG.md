# Changelog / 変更履歴

## Unreleased
- (EN) Add an embedded-font generator (§8.7.7). Rasterize a web font or your own typeface at a chosen size for a chosen character set and get a `lgfx::U8g2font` header — 1bpp, in flash, no runtime loading, drawn with `setFont(&MyFont)`. Character-set presets cover ASCII/Latin-1, Japanese (mini/full), CJK, SC/TC/KR, plus curated **units & symbols** and **clock/date** sets; the units set exists because the usual Japanese-mini list has `°` but not `℃` (U+2103). Available two ways from one pipeline: a standalone page (`docs/fontgen.html`) that just downloads a `.h` and needs no project, and Fonts mode in the editor, where the font is adopted onto the project and emitted into the exported header under the same per-profile flash policy as preset fonts.
- (JA) 埋め込みフォント生成機能を追加（§8.7.7）。Web フォントや手持ちの書体を、指定したサイズ・指定した文字種でラスタライズし、`lgfx::U8g2font` のヘッダとして出力する。1bpp・フラッシュ常駐・実行時ロード不要で、`setFont(&MyFont)` で描ける。文字種プリセットは ASCII/Latin-1、日本語（ミニ/フル）、CJK、簡体/繁体/韓国語に加え、独自の**単位・記号**と**時計・日付**を用意した。単位セットがあるのは、よく使われる日本語ミニの文字リストに `°` はあっても `℃`（U+2103）が無いため。使い方は 1 つのパイプラインで 2 通り: プロジェクト不要で `.h` をダウンロードするだけの単独ページ（`docs/fontgen.html`）と、エディタの Fonts モード（プロジェクトに採用し、プリセットフォントと同じプロファイル単位のフラッシュ方針で出力ヘッダに埋め込む）。
- (EN) A generated font is stored on the project as a **recipe** (typeface, size, characters) — never as glyph bytes. The data is rebuilt at export, so project files stay small and a shared project carries no redistributable copy of a typeface. Google fonts re-fetch automatically; a typeface supplied as a local file has to be supplied again, and the tool says so rather than exporting a header with the font missing.
- (JA) 生成フォントはプロジェクトに**レシピ**（書体・サイズ・文字種）として保存し、グリフデータは保存しない。データは出力時に再生成されるため、プロジェクトファイルは小さいままで、共有したプロジェクトが書体の再配布可能なコピーを抱え込むこともない。Google Fonts は自動で再取得され、ローカルファイルで与えた書体は再指定が必要になるが、フォントが欠けたヘッダを黙って出力せず、その旨を表示する。
- (EN) Curated web fonts are limited to SIL Open Font License 1.1 and Apache-2.0 families, which permit embedding the generated data in firmware. Local files are allowed with a prominent warning that most commercial and OS-bundled typefaces forbid exactly this, and every generated header carries an attribution block naming the typeface, author, licence and origin.
- (JA) 掲載する Web フォントは、生成データのファームウェア埋め込みを許諾する SIL Open Font License 1.1 と Apache-2.0 の書体に限定した。ローカルファイルも使えるが、市販フォントや OS 同梱フォントの多くがまさにこれを禁じている旨を明確に警告する。生成されるヘッダには必ず書体名・作者・ライセンス・入手元の帰属ブロックを含める。
- (EN) Add transparent scenes (§8.16): a scene can be marked as an overlay, drawn on top of the screen already on the panel with no background of its own — a dialog with rounded corners or a shadow shows the running screen through it, and the screen below is never redrawn. Buffered builds push the frame through LGFXVirtualCanvas `renderTransparent()` with a project-wide color key (`project.transparentColor`, default `#002400` = `TFT_TRANSPARENT`); direct builds simply skip the background fill, which is equivalent. New example `DialogM5Unified`, and `Screen::supportsTransparentScenes()` reports whether the build honors it.
- (JA) 透過シーンを追加（§8.16）: シーンをオーバーレイ指定すると、自前の背景を持たず、パネルに出ている画面の上に重ねて描かれる。角丸や影のあるダイアログの外側からは動作中の画面が見え、下の画面は描き直されない。バッファ構成では LGFXVirtualCanvas の `renderTransparent()` にプロジェクト単位の抜け色（`project.transparentColor`、既定 `#002400` = `TFT_TRANSPARENT`）で転送し、直描画構成では背景を塗らないだけで等価になる。サンプル `DialogM5Unified` を追加。ビルドが対応しているかは `Screen::supportsTransparentScenes()` で分かる。
- (EN) Requires LGFXVirtualCanvas **1.4.0 or newer** for transparent scenes in a buffered build; an older version draws them as ordinary opaque screens and emits a `#warning`, so projects that do not use the feature keep building unchanged.
- (JA) バッファ構成の透過シーンには LGFXVirtualCanvas **1.4.0 以降**が必要。それより古い場合は通常の不透明画面として描き `#warning` を出すので、この機能を使わないプロジェクトは従来どおりビルドできる。
- (EN) `SceneDesc::transparent` and `Project::transparentColor` are appended to the descriptor and emitted **only when a scene uses them**, so a project without a transparent scene generates byte-identical output and its `.lgfxsb.json` is unchanged — `formatVersion` stays 1 (SPEC §9.2, Layer 1).
- (JA) `SceneDesc::transparent` と `Project::transparentColor` は記述子の末尾に追加し、**使うときだけ出力**する。透過シーンを持たないプロジェクトの生成物はバイト単位で同一、`.lgfxsb.json` も不変で、`formatVersion` は 1 のまま（SPEC §9.2 レイヤ1）。
