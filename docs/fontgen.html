1 Typeface

Only SIL Open Font License 1.1 and Apache-2.0 families are listed — both allow the generated glyph data to be embedded in and shipped with your firmware.

Check the licence before you use this.

Generating an embedded font converts the typeface's glyphs into data that ships inside your firmware — that is redistribution. Many fonts, including most commercial fonts and the ones bundled with Windows, macOS and Office, do not permit it. Only use a file here if its licence explicitly allows embedding and redistribution. The generated header records that the source was a local file with an unknown licence.

2 Size & name

The size is the LINE HEIGHT in pixels, the way LovyanGFX names its own fonts (lgfxJapanGothic_16 is 16 pixels tall) — not a CSS font-size. Output is 1bpp, so each pixel is either on or off; the threshold decides how much anti-aliased coverage counts as "on", and lowering it makes the font heavier.

How to use the generated header

      
#include <M5Unified.h>      // or <LovyanGFX.hpp>
#include "MyFont.h"

void setup() {
  M5.begin();
  M5.Display.setFont(&MyFont);
  M5.Display.drawString("25.6℃", 10, 10);
}
