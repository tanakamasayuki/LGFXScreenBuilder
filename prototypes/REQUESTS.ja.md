## 共通 — 全画面に反映する方針

- [x] **破壊的操作（削除など）には確認ダイアログ**を出す（Profiles だけでなく全画面共通。プローブに順次反映）
- [x] **備考（description）を全要素に持たせる**（Scene/Group/Part/Asset/Slice/Profile）。任意・低優先の欄、空なら出力しない（SPEC §8.13 反映済み）

## Scene（シーン）

- [x] シーン用プロパティ画面（Design 内）で**シーンの備考(description)**を編集可能にする（§8.13 で全要素が対象）。実装: **パーツ未選択時＝右ペインに画面（シーン）プロパティを表示**（画面の空き領域・枠外クリック、またはシーン一覧クリックで未選択になる）。シーン名・パーツ数・備考を表示、回転はプロファイル単位なので出さない
- シーン別の回転は持たせない（回転はプロファイル単位。シーン別は §15 後回し）

## Profiles 画面 (profiles.html)

- [x] **対象ライブラリで割り当て候補ボードが変わる**（M5GFX/M5Unified=全M5ボード、素LovyanGFX=判定可能サブセット＋未収録は手動）。ライブラリはプロジェクト作成時に選ぶ、変更は Devices 画面 — プローブに selector 実装済み・SPEC §9/§8.9 反映済み
- [x] **ライブラリ変更で判定不可になった割り当ては保持＋警告**（自動削除しない）。実機は解像度フォールバック/手動 setProfile。チップとバナーに「自動判定不可」警告を表示 — 実装済み・SPEC §8.9.5 反映済み

- [ ] ボードカタログは**出せるだけ全ボードを表示**する。プロファイルのサイズに合わない（寸法不一致）ボードは「**非表示**」フィルタを**デフォルト ON** で隠す（トグルで表示に切替可能）
- [ ] 「**縦横入れ替え**」ボタンは**削除候補**。回転との役割差が分かりにくく、本来は回転で対応すべき箇所を誤って変更してしまいそう。向きは回転で扱う方針に寄せる

## Design 画面 (design.html)

- [x] **確定モデル（各プロファイル独立フルレイアウト・オーバーライド概念なし）で再作成済み**（旧 design-overrides.html を置換）。プロファイルタブ切替＝そのプロファイルの配置を直接編集／継承・上書きバッジ・「ベースに戻す」は撤去／default は左ペインに表示のみ
- [x] **プロファイルの追加（＝クローンで新規）は Design に置かない**。Profiles 画面の責務とし、Design はタブ切替＝配置編集に専念（＋タブを撤去）
- [x] **シーン一覧を左ペイン上段に追加**。二軸操作（左ペイン=シーン × 上タブ=プロファイル、直交）。各プロファイルがシーンごとに独立レイアウト（`layout[sceneId][partId]`）。シーン切替でパーツ集合とキャンバスが入れ替わる。Boot/Main/Settings のダミー3シーンで検証
- [ ] **default プロファイルとの差分ハイライト**は将来検討（後回し §8.13）。本プローブには未実装

- [x] **文字サイズは倍率を保存値に確定**（LGFX `setTextSize` 相当）。エディタは倍率入力＋px 高さの補助表示（基準高×倍率）。SPEC §8.7/§8.14 反映済み、design.html を倍率ベースに変換済み（基準高8px・0.25刻み・「≈ Npx」ライブ表示）。「px 高さ入力→倍率自動選択」の逆引きは後回し（§15）
- [x] 選択パーツを**矢印キーで1ドット移動**（Shiftで10px）— 実装済み

## 共通 — キーアサイン（今後 SPEC に統一）

プローブ間で操作を統一し、確定したら SPEC（エディタ操作）に明記する。現状の暫定キーマップ:

- 矢印：選択要素を**移動** ±1px
- Ctrl（⌘）+矢印：移動 ±10px
- Shift+矢印：**リサイズ**（→/←=幅、↓/↑=高さ）±1px
- Ctrl+Shift+矢印：リサイズ ±10px
- マウスホイール：キャンバス/画像の拡大縮小
- **Delete / Backspace：選択要素を削除**
- **マウス中ボタン＋ドラッグ：パン（表示移動・CAD風）**
- 画面のズームUI（−／％／＋）と「100%に戻す」ボタン（キーではなく UI）

- [x] このキーマップを確定し SPEC に記載 — **SPEC §8.14「エディタ操作（キーマップ）」**として明記済み（選択/解除＝画面プロパティ表示、矢印移動±1/Shift±10、Ctrl+矢印リサイズ、ドラッグ移動ライブ更新、Del削除、ホイールズーム、中ボタンパン、ズームUI、TIPS）。レイヤー順の `↑`/`↓` はパネルのボタンであり矢印キー移動と別物、と §8.3 を明確化
- [x] 操作ヒント（ショートカット）の TIPS 欄を画面右下に表示 — 各プローブに実装済み（design.html / assets.html ほか）
